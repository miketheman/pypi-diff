Comparison Logic

modified
Files exist on both sides but have meaningful content differences beyond name/version/whitespace.
added
File exists only in package B.
removed
File exists only in package A.
moved
File exists on both sides at different paths with the same filename and identical content. Detected by matching basenames between added and removed files. Empty files are never matched.
equivalent
Files differ only in ways explained by the package name, version, or whitespace. Detected by replacing all occurrences of each package name (including hyphen/underscore variants) and version with placeholders, then comparing. Names inside URLs are not replaced. RECORD files are compared by normalized file path list only, ignoring hashes and sizes (which change with name length).
identical
For sdists, the content is byte-for-byte the same. For wheels, the size and CRC-32 recorded in the archive match; the content is not downloaded, and a CRC-32 can be forged. Open the file to diff the real content.

Similarity %

Overall ring counts identical + equivalent + moved files. Per-file % is a size ratio approximation for modified files.
